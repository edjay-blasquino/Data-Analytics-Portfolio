# 📊 Sales Performance Dashboard

![Dashboard Preview](Dashboard%20Preview.png)

## Project Overview

I developed an interactive **Sales Performance Dashboard using Microsoft Excel** to transform raw sales transaction data into an interactive reporting and analysis tool.

The workbook analyzes **300 sales transactions** covering **January 2025 to March 2026**. It provides management-level KPIs and allows users to dynamically filter results by **region, product category, customer type, salesperson, and date**.

**PivotTables** and **PivotCharts** were used as the analytical foundation, while **Slicers** and an **Excel Timeline** were implemented to provide an interactive user experience.

## 📌 Key Dashboard Features

### 📊 KPI Monitoring

The dashboard displays the following key performance indicators:

- **Total Net Sales:** ₱6,750,869.00
- **Total Orders:** 300
- **Quantity Sold:** 1,720
- **Average Order Value:** ₱22,502.90

### 📈 Sales Trend Analysis

- Monthly sales performance is visualized using a **line chart**.
- Allows users to identify changes and trends in sales performance over time.

### 🌎 Regional Analysis

Sales performance can be compared across:

- South
- North
- West
- East

### 🛒 Product Analysis

- Identifies the **Top 5 Products by Net Sales**.
- Helps compare product performance and identify high-performing products.

### 👥 Customer Analysis

Sales performance can be evaluated based on customer type:

- Retail
- Government
- Corporate

### 👨‍💼 Salesperson Analysis

Users can compare salesperson performance based on:

- Net Sales
- Order Count
- Average Order Value

### 🎛️ Interactive Filtering

The dashboard includes interactive filters for:

- Region
- Product Category
- Customer Type
- Salesperson
- Year
- Quarter
- Month
- Day

The **KPI cards and charts respond dynamically** to the selected filters, allowing users to explore different segments of the dataset.

## 🎯 Project Objective

The primary objective of this project was to demonstrate how raw sales transaction data can be transformed into an **interactive and management-friendly reporting dashboard** using Microsoft Excel.

The dashboard enables users to:

- Monitor overall sales performance
- Identify sales trends over time
- Compare regional performance
- Analyze product performance
- Evaluate customer segments
- Compare salesperson performance
- Dynamically filter and explore sales data
